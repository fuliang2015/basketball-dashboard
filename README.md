# Basketball Journey — Phase 1 PWA

A mobile-first personal basketball development tracker (not an official school app).

## Included
- Home, Progress, Games, Team & Me, Post-game Check-In
- Editable goals, manually entered game statistics and context (coach/role)
- Local device storage, JSON export/import, basic offline support
- No login, no automatic PDF extraction, no AI analysis

## Publish to HTTPS
1. Open **Settings → Pages** in this GitHub repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the default branch (usually **main**) and **/(root)**, then Save.
4. Wait for the Pages deployment to complete.
5. Expected URL: https://fuliang2015.github.io/basketball-dashboard/

## Install on iPhone
Open the HTTPS URL in **Safari**, tap **Share → Add to Home Screen**, enable **Open as Web App**, then **Add**.

## Privacy and backups
The website is public, but no real personal box scores, photos or reflections are included in source code. Data entered into the app is stored on that device only. Use **More → Export JSON backup** regularly and keep backups private. Clearing browser data can erase records. Do not commit backups to the public repository.

The app currently uses a generic basketball icon and school-inspired colors, not an official crest.
